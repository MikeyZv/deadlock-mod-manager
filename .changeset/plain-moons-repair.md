Name 1-click downloads after the creator's file and keep their other files listed

A mod installed from a 1-click link was saved as `gamebanana-1234567.zip` rather than the name its creator uploaded, and only the clicked file was recorded — so the mod had no Manage Files list to pick another version from. Downloads now take the creator's name wherever one is available, and the full file list is kept. Mods added before this change get their list back the next time you open them.
